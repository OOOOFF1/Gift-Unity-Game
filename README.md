# Unity 2D 像素风横版平台跳跃游戏

## 项目简介

本项目是一款基于 Unity 和 C# 开发的 2D 像素风横版平台跳跃游戏 Demo，主要用于实践游戏客户端开发、角色控制、战斗交互、关卡管理和数据存档等功能。

玩家可以控制角色进行移动、跳跃、二段跳和冲刺，使用武器攻击敌人，与 NPC 进行对话，并通过关卡选择界面体验关卡切换、通关、重试及存档等功能。

本项目目前以核心玩法实现和功能测试为主，主要体验内容集中在第一个关卡。

## 游戏操作

| 按键 / 操作 | 功能说明 |
|---|---|
| `A` / `D` | 控制角色向左 / 向右移动 |
| `Space`（空格） | 跳跃，支持二段跳 |
| `Left Shift`（左 Shift） | 冲刺 |
| 鼠标左键 | 射击 |
| 鼠标右键 | 切换武器显示 |
| `F` | 与 NPC 对话 |
| `Esc` | 打开暂停菜单 |

## 游戏功能

### 1. 角色控制

- 支持左右移动、跳跃、二段跳和冲刺。
- 使用 Unity 2D 物理系统处理角色移动与碰撞检测。
- 通过不同移动机制增强平台跳跃过程中的操作体验。

### 2. 战斗系统

- 支持武器射击和子弹碰撞检测。
- 实现玩家子弹与敌人的交互。
- 使用对象池复用子弹，减少频繁创建和销毁对象带来的开销。

### 3. 场景交互

- 支持场景道具收集。
- 支持 NPC 对话交互。
- 支持关卡切换以及通关、死亡后的相关操作。

### 4. 关卡管理

- 提供关卡选择界面。
- 支持关卡解锁、关卡选择界面翻页和关卡切换。
- 提供通关、重新开始和返回关卡选择界面等功能。

### 5. 存档系统

使用 JSON 保存玩家和关卡相关数据，包含：

- 玩家在关卡中的位置。
- 玩家生命值。
- 道具收集进度。
- 已击败敌人的状态。
- 关卡解锁进度。

通过唯一 ID 标记已收集道具和已击败敌人，为关卡状态恢复提供支持。

### 6. 游戏 UI

- 暂停菜单。
- 死亡提示与重试界面。
- 通关提示与下一关入口。
- 关卡选择界面。
- 音量设置。

## 关卡说明

本项目目前处于 Demo 和功能测试阶段，各关卡的设计目的有所不同。

- **第一个关卡：** 主要体验关卡，用于体验游戏的核心玩法，包括角色移动、跳跃、冲刺、射击及场景交互等内容。
- **后续关卡：** 基于第一个关卡复制，用于测试关卡切换、关卡解锁、通关流程、存档恢复及其他相关功能。

后续关卡目前主要承担功能验证用途，并非完全独立设计的正式关卡。部分场景布局、内容或玩法可能存在重复，后续可根据开发进度继续完善。

## 技术实现

- **开发引擎：** Unity
- **开发语言：** C#
- **项目类型：** 个人开发项目
- **游戏类型：** 2D 横版平台跳跃
- **美术风格：** 像素风

### 核心技术点

- 使用 `Rigidbody2D` 和 `Physics2D` 实现角色移动与碰撞检测。
- 实现角色移动、跳跃、二段跳、冲刺等控制逻辑。
- 实现武器射击、子弹碰撞和敌人交互。
- 使用对象池管理子弹对象，减少重复实例化与销毁。
- 使用唯一 ID 跟踪道具收集状态和敌人击败状态。
- 使用 JSON 实现玩家数据和关卡进度的持久化存储。
- 将角色控制、角色状态、存档管理和关卡 UI 拆分为独立脚本，降低模块之间的耦合，便于维护和调试。

## 运行方式

### Windows Demo

1. 下载游戏压缩包。
2. 解压到本地文件夹。
3. 确保游戏 `.exe` 文件、对应的 `_Data` 文件夹及其他构建生成的必需文件均保留在原有目录结构中。
4. 双击 `.exe` 文件启动游戏。
5. 通过开始界面和关卡选择界面进入游戏。

**注意：** 不要单独移动或分发 `.exe` 文件。Unity Windows 构建通常需要配套的数据文件和运行库才能正常运行。

### Unity 项目源码

如果需要在 Unity 编辑器中运行或查看项目源码：

1. 安装与项目兼容的 Unity 编辑器。
2. 使用 Unity Hub 打开项目根目录。
3. 等待资源导入和脚本编译完成。
4. 打开项目的启动场景。
5. 点击编辑器中的 `Play` 按钮运行。
