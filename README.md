# Unity 2D 像素风横版平台跳跃游戏

## 游戏简介

这是一款使用 Unity 开发的 2D 像素风横版平台跳跃游戏。玩家可以控制角色移动、跳跃、冲刺，使用武器攻击敌人，与 NPC 对话，并体验关卡挑战与进度存档等功能。

## 游戏操作

| 操作 | 按键 |
|---|---|
| 左右移动 | A / D |
| 跳跃、二段跳 | 空格键 |
| 冲刺 | 左 Shift |
| 射击 | 鼠标左键 |
| 切换武器显示 | 鼠标右键 |
| 与 NPC 对话 | F |
| 打开暂停菜单 | Esc |

## 游戏功能

- 角色移动、跳跃、二段跳与冲刺
- 武器射击与敌人交互
- 道具收集与 NPC 对话
- 关卡选择、解锁、通关与重试
- 玩家状态及关卡进度存档
- 暂停菜单与音量设置

## 说明

第一个关卡是主要体验关卡，用于体验游戏的核心玩法。

后续关卡为复制关卡，主要用于测试关卡切换、解锁、存档及其他游戏功能，目前并非完全独立设计的正式关卡。

整个项目的bgm还没找到合适的所以还没有配置，暂停菜单里的第一个音量按钮是bgm的，第二个是视频的。
