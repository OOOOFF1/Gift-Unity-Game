# Unity 2D 像素风横版平台跳跃游戏

## 项目简介

使用 Unity 和 C# 独立开发的 2D 横版平台跳跃游戏，主要用于实践游戏客户端开发、角色控制、战斗交互、关卡管理与数据存档。

## 核心功能

- **角色控制：** 移动、跳跃、二段跳、冲刺。
- **战斗系统：** 武器射击、子弹碰撞、敌人交互。
- **场景交互：** 道具收集、NPC 对话、关卡切换。
- **关卡管理：** 关卡解锁、翻页选择、通关与重试。
- **存档系统：** 使用 JSON 保存玩家位置、生命值、收集进度及敌人状态。
- **游戏 UI：** 暂停菜单、死亡与通关弹窗、音量设置。

## 技术亮点

- 使用 Rigidbody2D 与 Physics2D 实现角色移动和碰撞检测。
- 使用对象池复用子弹，减少频繁创建和销毁对象。
- 使用唯一 ID 记录已收集道具和已击败敌人，支持关卡状态恢复。
- 将玩家控制、状态管理、存档和关卡 UI 拆分为独立脚本，便于维护与调试。
